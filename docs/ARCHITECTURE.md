

## Accessibility engineering baseline

The implementation and release requirements for the IWAG V2 accessibility scope are maintained in [ACCESSIBILITY-ENGINEERING-SPEC.md](./ACCESSIBILITY-ENGINEERING-SPEC.md). This specification separates normative WCAG 2.2 Level A/AA requirements from additional cognitive-accessibility, neuroinclusive interaction, privacy, and disability-inclusive co-design recommendations. Accessibility acceptance is evidence-based and is not determined by CI/CD status alone.
