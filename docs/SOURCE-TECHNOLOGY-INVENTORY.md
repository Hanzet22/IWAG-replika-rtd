## 4. Rust Active Compiler

The Rust CLI now exists at `compiler/iwagc/` with a project manifest at `iwag.compiler.toml`.

Current commands:
- `inspect`: inventory the declared V2 source root.
- `doctor`: check Node, npm and Cargo availability.
- `dev`: launch Astro dev through the Rust orchestrator.
- `build`: validate source paths, invoke Astro/Vite, count generated HTML and write a build report outside the public output.
- `preview`: launch Astro preview through the orchestrator.
- `wasm`: build the existing contrast-engine module through wasm-pack.

The normal npm build now enters through the Rust compiler. The compiler is an orchestrator and project-specific validator; Astro/Vite, Panda, StyleX and Tailwind remain the specialist language/build backends.

## 5. CSS compiler integration

- Tailwind CSS 4 remains utility styling.
- Panda CSS is integrated through `@pandacss/vite` 2.6.0 with preflight disabled and generated output ignored.
- StyleX is integrated through the official `@stylexjs/unplugin` 0.19.2 and `@stylexjs/stylex` 0.19.2 packages.
- StyleX owns atomic component-level styles; Panda owns the typed token/recipe layer; Tailwind owns low-level utility composition; plain CSS owns semantic foundations and fallbacks.
- CSS layer order is declared centrally in `src/styles/compiler-layers.css`.

This is an initial integration, not yet a full route-level styling migration or verified bundle-size result. The active workflow is expected to surface integration defects; work continues independently of CI status.
